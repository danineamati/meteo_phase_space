# Meteorology Phase Space

Investigate the temperature versus precipitation phase space trajectories in comparison to normals and Köppen classification.

## Data

### Meteorology Data

Meteorology data is sourced from Meteostat Stations (please visit [https://dev.meteostat.net/python](https://dev.meteostat.net/python) for more information).

### Köppen Classification

Köppen is adapted from the [`salvah22/koppenclassification`](https://github.com/salvah22/koppenclassification) repository. Specifically, the focus here is to vectorize all the code for speed with `numpy`.
